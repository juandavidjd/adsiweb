
ECOSISTEMA ADSI — Versión Cinematográfica
----------------------------------------
Abre index.html en tu navegador para escuchar la experiencia audiovisual.
Los audios están en formato MP3, sincronizados con el scroll.

Estructura:
  /audio       → narraciones y efectos
  /images      → logo y visuales
  /index.html  → interfaz principal


Documentación estratégica:
  docs/ODI_VISION_OPERATIVA.md  → visión operativa unificada de ODI

Nueva interfaz ODI:
  liveodi.html  → experiencia de presencia ODI (stats dinámicos + voz + input invisible)

VIVIR (base técnica):
  viver/  → overlay Electron + telemetría WebSocket + manifiesto ejecutable

Ordenes Claude Code:
  docs/ORDEN_CLAUDE_CODE_VIVIR_EJECUCION.md  → orden operativa para lectura y ejecución de VIVIR
